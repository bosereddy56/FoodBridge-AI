# FoodBridge AI

FoodBridge AI is an AI-powered food donation platform that connects restaurants with NGOs to reduce food waste and help communities in need.

## Features

- Restaurant Food Donation
- NGO Claim System
- Admin Dashboard
- AI Food Scoring
- AI Recommendations
- AI Predictions
- Donation History
- Real-time Donation Tracking

## Tech Stack

Frontend:
- React.js
- Tailwind CSS
- Axios

Backend:
- Node.js
- Express.js

Database:
- MongoDB

AI Features:
- Food Quality Scoring
- NGO Recommendation Engine
